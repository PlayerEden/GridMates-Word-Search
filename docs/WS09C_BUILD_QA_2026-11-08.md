## Product change

- **New Puzzle is now a separate pre-game screen** accessible from Home, My Puzzles, gameplay Options and the results' Play another puzzle action, rather than a mutation-triggering dialog inside a live board.
- Theme, board size and challenge are selected **before** starting. Only current working 12×12, 15×15 and 20×20 presets are offered; 25×25+ are future WS-09E/F work.
- Solo/Daily/Nearby play modes continue to have distinct Home launchers. **Continue Solo** and **My Puzzles** remain separate paths; Daily's fixed board/nearby host setup unchanged.
- **Cancel/system Back does not mutate the session.** New Solo is committed only when Start puzzle succeeds, archiving any unfinished current board via schema5. A full library or write error leaves the old profile in place and reports a warning.
- The most recently *successfully started* Solo theme/board/challenge defaults are stored in local preferences and survive same-ID app restarts/updates. Invalid settings safely fall back to a valid known book preset; these preference defaults are **not yet included in manual portable JSON backups**. The actual puzzle progress is still backed up in schema5.
- The in-game **Customize puzzle** dialog and direct New-game mutation were removed. In-game Options can route to pregame. Existing hints and feedback controls retained.
