## Original art, source and correctness

- The 12 canonical, approved Woodland PNG portraits were reused from `PlayerEden/SudokuTogether` at **pinned commit `975e31a1e8cbfebad1fbbc7602b3340c357da7ef`**, not generated substitutes.
- [Word Search original-asset manifest](../design/woodland/approved-portrait-reference.json) captures canonical stable IDs, filenames, byte sizes, and expected SHA-256 for each.
- `scripts/import_woodland_portraits.py` checks exactly 12 unique expected names, PNG header, exact size and expected source SHA-256 **before copying any PNGs** into Android `drawable-nodpi`.
- [Android QA workflow](../.github/workflows/ws01-android-qa.yml) checks out the source at the pinned commit, runs verification/import and fails if any of the twelve entries is missing from the compiled APK.
- Source repository PNG binaries are not committed to Word Search Git; this is an intentional reproducible pinned import at **build time**. A local build without importing art shows clearly labeled monogram fallbacks, while the tested CI APK contains the actual original art.
- The Collection UI dynamically resolves approved resource IDs and displays original portraits; locked entries are visually muted. Actual on-phone crop/alignment/selection still needs review.
