## Implementation

- Two **new SOLO** book-size presets: `BOOK_GRAND` **25×25 / 32 words**, and `BOOK_GIANT` **30×30 / 44 words**. Existing 12×12/15×15/20×20 continue to appear in New Puzzle's board selector. **Daily and LAN/Nearby modes do not automatically gain these size choices.**
- Dedicated `WordSearchGeneratorV3` (`CONTENT_VERSION=3`) and `WordLibraryV3`, with **~79–81 individually curated Woodland, Space and Garden terms per theme**, 5–16 English A–Z characters. The engine uses bounded seeded placement sampling and validates exact target occurrences in all eight directions, rejecting selected substring pairs that would produce forced duplicates.
- Version dispatch is encoded in the new-board IDs (`wordsearch:v3:en:...`). Legacy board names/ordinals and both frozen v1/v2 generator sources stay unchanged. **Never retroactively edit a shipped v3 word pack or placement algorithm; create v4 for future changes.**
- Existing schema5 multi-session store accepts v3 found word IDs, hints, timer, seed and board/challenge, pausing and resuming v3 alongside old v1/v2 Solo games. Completed Solo history now accepts up to **44 words**. Larger boards receive **6 or 8 hint steps**, versus the preserved existing allowances for smaller boards.
- Zoom/pan, square paperback board, word-list paging and precise row/column selection are inherited from WS-09D. Physical readability at 30×30 remains an **owner test**, not inferred from a JVM test.
