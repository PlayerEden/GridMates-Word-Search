## Delivered gameplay and persistence

- Completed Shared Board Race has a friendly two-score comparison, winner/tie, scoring margin, and expandable list showing which words each player found. The comparison is based on the already host-validated shared claims. Co-op never generates a win/loss.
- Both players maintain **independent on-device journals**, with Played/Wins/Losses/Ties and recent races in Stats. Each room ID is recorded **at most once**, even after replay/rotation/reconnect or app restart; later duplicates do not change a stored outcome.
- Race results are kept inside the existing **atomic local SoloProfile** schema-4 JSON under an optional races array. Export, preview and confirmed Restore include that list. Import rejects impossible scores/duplicates. Old backups without races remain readable but carry no Versus history; restoring an old backup can replace current history, so preview warns before confirmation.
- The journal is bounded at 1,000 races and refuses further additions rather than silently deleting entries. Save-write failure does not claim success or intentionally overwrite the previous profile.
