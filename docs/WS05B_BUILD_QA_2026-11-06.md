## Feature behavior as coded

- **Chat:** Host-authoritative sender identity and message sequence; guest sends proposed chat; host validates, adds to bounded in-memory history and rebroadcasts. Chat composer is collapsed by default; last message stays visible. The latest partner-found word is derived from committed host claim data, **not** from speculative live cursor movement.
- **Reconnect:** Host includes the most recent 24 accepted messages in the guest's welcome, with state claim history. Both are temporary and lost when the host room is destroyed.
- **Safety:** Local-only, unencrypted TCP. Message max 140 characters; min 1.5 seconds per player; rate-limited/invalid messages rejected. Four simultaneous pre-admission socket handlers max. **Protocol v2** advertised via NSD to discourage mixed-version pairing. Existing Solo/Daily saves, puzzle seeds and original assets remain unchanged.
