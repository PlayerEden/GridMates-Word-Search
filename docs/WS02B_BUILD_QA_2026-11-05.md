## What changed

1. Pure Kotlin `WordDragSnap` selects one of eight directions with a minimum commitment threshold, a stable direction lock, boundary clamp and return-to-center release. JVM tests cover horizontal/vertical/diagonal/reverse, wobble, out-of-bounds and invalid numbers.
2. Native Compose board renders a **translucent rounded marker path behind the letters**: gold while dragging, soft green after a confirmed word. Found-word overlaps remain visually marked.
3. Board owns its drag gesture without competing with a full-screen vertical scroll parent; cell transitions provide gentle optional haptic feedback. A found word has a stronger optional haptic and optional system click. Sound is off by default and both toggles live in `Feel`.
4. Theme/difficulty controls moved to a `Change` dialog; `New Puzzle` requires confirmation. Active screen uses compact progress and puts an independently scrollable target list directly below the board in portrait or beside it in landscape.
5. Material3 container colors deliberately follow cream/forest/gold, Android system bars request dark indicators over light backgrounds, and bottom navigation now uses native vector-drawn glyphs rather than placeholder dots.
6. Added `design/asset-registry.json`: tracked prototype/procedural highlight and future generated raster/vector assets. **No original Woodland portraits or newly generated raster sprites are currently packaged.**
