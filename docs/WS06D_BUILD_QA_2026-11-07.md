## Verified functionality, safeguards and limits
- A recipient-specific **finished host-authoritative Speed Duel** snapshot now creates exactly one immutable local result for that room, derived from first-finish winner/loser and both counts. Invalid, incomplete, inconsistent or wrong-seat snapshots cannot award history. The private opponent word list is neither transmitted nor stored in the journal.
- **Stats** shows a separate Speed Duel Played/Wins/Losses/Words found and recent outcomes. Shared Board Race keeps its win/loss/tie journal and word-by-word shared-board recap; Solo and Daily statistics are unaffected.
- The existing AtomicFile/JSON backup has an **optional `duels` schema-4 array**, with first-write-once, 1,000-entry cap, compatible old saves, safe Export/preview/confirmed Restore and invalid/duplicate record rejection. Save failure does not claim success or overwrite earlier records.
- Both phones must run **protocol-v6-compatible** Nearby APKs; a version-v5 peer will not join, even for Co-op/Race. This does not provide encrypted LAN or robust anti-cheat; the deterministic board seed remains visible to locally modified clients.
- **Physical two-phone acceptance is still OPEN:** result delivery on both, reconnect/replay, simultaneous final word claim timing, optional room code/discovery, chat, rotation, 320dp/200%-font and actual handset update/restore. Emulator success is not physical proof.
- For stable-signed v0.5.9 from PR #41 or later, install newer QA APKs **over the existing app**; the exact historical v0.7.0→v0.7.1 path passed API35 emulator. Older, differently signed QA builds (v0.5.8 and the separate PR #40 screenshot v0.5.9) may require verified JSON export before uninstall and Restore afterward. Never clear app storage without backup.
