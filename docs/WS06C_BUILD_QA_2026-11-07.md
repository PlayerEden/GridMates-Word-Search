## Implemented and guarded

- New selectable Speed Duel mode with independent same-puzzle private word sets, both Ready before GO, no visible board/word list until GO, live per-player progress counts and host-authoritative first complete board decision; idle cannot finish the match.
- Independent Kotlin duel rules and separate mode-aware transport, no shared-board word theft. No opponent found-word IDs or paths are sent in ordinary guest state messages; only own word IDs, opponent count, readiness and winner. LAN protocol increments from v5 to **v6**, which intentionally makes older nearby APKs incompatible.
- Rejoin to a still-hosted room recovers private finds/result; guest must Ready again if disconnected before GO, while active round pauses claims while disconnected. Chat and other mode systems continue to use the existing nearby admission/reconnect.
- Existing Shared Board Race win/loss/tie journal and Solo/Daily profile saves are untouched by this new mode. **Speed Duel match history is not yet permanently recorded**; this is a future WS-06D milestone. No automatic cloud, anti-cheat, encryption or online play is claimed.
