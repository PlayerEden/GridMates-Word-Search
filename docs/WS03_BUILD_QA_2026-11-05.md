## Feature overview

- Existing native Solo Word Search generator, theme/difficulty, smoother direction snapping, marker ribbon highlights, haptic feedback and compact game layout.
- Offline active Solo progress saved to versioned app-private AtomicFile JSON. Restores found target IDs, hint levels, theme, difficulty, seed and active elapsed seconds. Completed results are idempotent and survive restart.
- Three-tier hints (zone, start coordinate, faint guide path) are counted honestly; no auto-completion.
- Real Records screen: completed games, words found, assisted completions, timestamps, hint count and solve time.
- Settings exposes Android Documents Export/Import of a JSON backup; imports parse/validate first and require explicit confirmation to replace current progress.
- Corrupt-save protection: unreadable previous bytes are left intact and writes are blocked, rather than silently replacing the file.
- Core JVM unit tests include state sanitization, repeated word claim prevention, hint sequence and idempotent records. Android instrumentation source includes an isolated save/reload/completion/export roundtrip test; it was COMPILED but NOT RUN in CI.

## Signing/update caution

The QA APK is signed by an ephemeral GitHub Actions debug key. Although package ID and version are distinct from Sudoku, it may not update an earlier QA build due to signing-certificate mismatch. Before uninstalling any WS-03 QA install **containing progress**, use Settings > Export to save a JSON backup outside the app. Then reinstall and Settings > Import if needed. No production signing, cloud sync or seamless APK update compatibility is claimed.
