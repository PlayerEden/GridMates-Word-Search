## What changed in WS-05E

- Android NSD nearby-room lookup now **serializes** older `resolveService` calls, deduplicates advertisements and caps the tracked room set at 32.
- Stopped or vanished service entries are removed. Each service-advertisement generation gets its own ticket, so late callbacks cannot revive a previously lost host under the same advertised name.
- Refresh clears old room results and waits until a previous discovery session stops before restarting, avoiding overlapping registrations. Lost/failed resolution can advance the pending queue.
- The screen offers a **Refresh** action and an **Interrupted join → Retry joining this game** card if a reconnect credential was durably saved but final `Joined` confirmation never arrived. The actual room ID and optional PIN are held in transient room memory for the retry.
- A single-flight guard blocks repeated taps from starting concurrent join attempts. Existing two-phase admission, room rotation ViewModel, bounded chat, host-authoritative word claims and Solo/Daily storage are unchanged.
- Added pure JVM discovery state-machine tests and **3 Android emulator tests** (36 now vs 33 in WS-05D). These validate internal logic, not true Wi-Fi multicast discovery.
