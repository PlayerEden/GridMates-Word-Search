## Scope / QA evidence

1. New non-monetized **per-puzzle Hint Policy**: 2 for Short (12×12) and legacy boards, 3 for Standard (15×15), 4 for Extended (20×20), and 2 for Daily. Extra requests blocked in **core** even if UI misbehaves.
2. Existing three-stage progression remains: row nudge → precise starting cell → path highlight, one step per action; never completes a target automatically.
3. HUD displays `Hint (N)` with remaining budget; Hint disabled at zero and after finishing. All hints are persisted in existing schema4 JSON with no migration; older clues/results/assisted history remain intact even if now over allowance.
4. **20×20 100% clipping candidate fix**: rows use parent square's distributed equal heights, children fill allocated row heights, preventing the cumulative pixel rounding of 20 separately sized square children that could crop the final row.
5. Existing `graphicsLayer` whole-board magnification, Move/Find state, compact two-row header, remaining-words panel and 12 Woodland art retained from previous CI-green PR #25.
6. Unit tests verify every allowance, Daily vs Solo enforcement, no extra hints when depleted, legacy over-budget save preservation, existing level-3 ladder progression, and solvable generated boards; Android test source verifies partial hint state and Daily persistence after restart/backup.
7. **No changes** to English v1/v2 word generator seeds/IDs or content versions, Offline Daily identity, local-save schema, project packages, monetization, collections, Spanish or multiplayer.
