## Implemented and tested at the source/build layer

- Local ISO-calendar-date and generator-version-based deterministic Daily puzzle seed, with a simple versioned theme rotation and 8×8 Easy mode.
- Today's puzzle and prior dated entries persist independently from Solo; past unfinished dates remain accessible and date completion cannot be counted twice.
- Daily reuses Solo's grid, drag snapping, rounded highlight ribbon, hints and feedback.
- Save schema v2 adds Daily entries to the same atomic private JSON save; decoder retains support for schema-v1 Solo saves and Android export/import backups.
- Updated Records includes Daily completion count. The Android document restore preview includes Solo/Daily totals.
- Foreground gate added for Solo and Daily active timer ticks so background duration isn't counted.
- Pure-JVM `DailyChallengeTest` for date validation, reproducibility, seven-day generator checks, different dates, idempotence and mismatched board identity. ## Signing and release caveats

QA APKs use temporary GitHub Actions debug signing, so a new build may not install over an older `.qa` package. **Never uninstall a Word Search QA app with valuable local progress before Settings > Export.** Uninstallation removes private saves, and there is no cloud restore. Sudoku has a separate install identity and must not be uninstalled. Stable protected QA signing is still unresolved; nothing here is a production-signed Play release.

Daily gifts, stamp currency, new profile art/sprites, achievements and cross-game collections are future reviewed designs and **not shipped** by this checkpoint.
