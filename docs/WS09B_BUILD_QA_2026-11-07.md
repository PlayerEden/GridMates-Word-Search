## What v0.8.8 does

- `SoloProfile.active` remains the current puzzle, retaining the familiar gameplay APIs. A new `pausedSolo` field saves up to **24 unfinished Solo runs** in the SAME atomic private profile and portable JSON export. Every archived run carries its original seed/content version, found word IDs, hint levels and active elapsed timer.
- New Solo or changed options archives unfinished current Solo instead of replacing it. Resuming a paused game swaps the current unfinished game into the library. Completed games remain in Records and don't occupy paused slots. The bounded library refuses to evict games silently when full.
- Home now opens **My Puzzles**, which lists current and paused puzzles, offers Resume, and requires a clear confirmation for removing a paused puzzle. New Solo is reachable there, and the current-puzzle Home action remains immediately accessible.
- Schema 1–4 manual backups migrate to schema 5 with `pausedSolo: []`, retaining the active puzzle, Daily, identity, completed Solo results and Race/Duel journals. Invalid/corrupt/duplicated/overlimit paused journals fail CLOSED without replacing the original bytes.
- Source generators v1/v2, the nine historical golden puzzle fingerprints, challenge rules, LAN v7 and test-only signing are unchanged.
- `AtomicFile` still performs all-or-nothing disk replacement. The new start/resume/remove operations additionally roll back their in-memory profile on write failure.

## Gates NOT passed / caution

- Family tester's **specific older installed APK version and signer remain unverified**. Do not uninstall or clear data. v0.5.8 and earlier QA builds have different signer and require an independently verified migration path. The run validates exactly v0.8.7 → v0.8.8, not the unspecified real family phone.
- **Schema5 cannot safely be downgraded to a schema4-only executable** by simply installing an older APK: old code will refuse to read the newer profile. Rollback means reverting code with compatible new-schema reading or following a tested backup/export conversion, never deleting the only saved data.
- 24 slots are a deliberate initial bound, not a lifetime cap on game content; app warns if full and only the player can remove one.
- The first pass uses AtomicFile, not Room. **Session timestamps, saved scroll/zoom, pre-game choice UI** and performance scaling beyond 20×20 are separate WS-09C/D/E/F work.
