## Specific implemented changes

1. **Pressable cabinet hardware** (`WS16BICabinetChrome.kt`): `MutableInteractionSource` and `collectIsPressedAsState` drive an `animateFloatAsState` 115ms down-press and release for Back/menu/Prev/Next when using the high-res cabinet. Only the 44dp *visual face* scales down approximately 5.2% and translates 1.5dp down; the existing 54dp `Box.clickable` semantics, enabled/disabled callback and actual hit target remain unchanged. A subtle brass stroke/glint brightens under the finger; the cast shadow tightens. No infinite animations, sound, confusing auto-activation or extraneous haptic permissions. `ValueAnimator.areAnimatorsEnabled()` makes these changes instantaneous when Android animations are disabled.
2. **Pager response** (`WS16BKBookcasePager.kt`): stable non-tappable dots animate their active radius and warm brass halo for 165ms after page state change, again instant when platform animation disabled. The current 7-dot viewport, spoken `Page X of Y` semantics, real pager state and previous/next disabled gates remain. Pager rail width reduced **254dp -> 242dp** (height still 62dp); dots shrink 17 -> 16dp to preserve seven visible indicators and the original 54dp arrow hit targets without clipping. Original pinned rail image is reused, scaled only in layout; no new asset or binary mutation.
3. **Bookcase title/blank depth touch-up:** the “Your Library” plaque moves **8dp upward** (`top-80dp` to `top-88dp`, safe floor 12dp) to clear actual spines without moving books. Native `WS16BIUnletteredBlankSpine` opacity increases **0.62 -> 0.75** so embossed gold/color reads less transparently while still visibly secondary and NON-interactive. No fake titles, no IDs, no touch behavior.
4. **Tests & continuous delivery:** `test_ws16bl_motion_depth.py` verifies 54dp unchanged hit area, platform reduced-motion handling, no perpetual effect loops, existing click/disabled semantics, 115/165ms durations, seven-dot cap and paged real-book catalog intact. Previous `test_ws16bj_carved_title.py` geometry and expected new position updated. Both existing GitHub workflows execute the new guards plus all prior source-art and release isolation checks. Android `versionCode=71`, `versionName=0.9.27-library-tactile-polish`, same `com.playereden.gridmates.wordsearch.qa` QA package and pinned public test signing key as v70. Install over v70 WITHOUT uninstall/clearing data when APK is validated.
