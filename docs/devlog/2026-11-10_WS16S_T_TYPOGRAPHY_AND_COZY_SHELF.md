Shared *intent* applies to the series, but no actual Sudoku code change in this Word Search pass.

## License/provenance / no vendor lock-in
- Both fonts were sourced from Google’s open font repository and offered under SIL Open Font License 1.1. According to [SIL’s own FAQ](https://software.sil.org/oflt/), an application (including a sold game or mobile app) can bundle original OFL fonts without licensing the whole game under OFL; fonts may not be sold alone, the redistributed font license notices must accompany them, and modified fonts with reserved names may require renaming.
- **Atkinson Hyperlegible** already appeared in `design/font-library-approved-b5.json` with source-pinned Google Fonts commit `24ddc1f324cac5d9f5aedca126d298f56e3f1640`, Git blob SHA and SHA-256.
- **Literata** added as fifth entry to the *same pinned source commit* and exact upstream font Git blob SHA `0a81b4984a4a4eb101e0ddc28babc85bb137efef`, 955,132 bytes, matching official OFL notice SHA `9d3b4e3b1e9068fbda799f57833ff831d05cc271`, 4,389 bytes. The current import validates pinned Git blob hashes and byte counts; no independent SHA256 value was asserted for the new source. `scripts/import_font_library.py` imports unchanged source binary and its complete legal notice into `app/src/main/res/font/gm_literata.ttf` and `app/src/main/assets/font_licenses/literata_ofl.txt`. No network dependency after app installation and no font file supplied directly to end users.
- Both GitHub QA workflows now sparsely check out this fifth family from the already-pinned Google Fonts commit, use the same import script, and bundle the font in the Android app. Android QA also checks five font IDs/notice paths are in the resulting APK.
- **Future GridMates series tokens**: `GridMatesStoryTypeface = Literata` for headings/section titles, `GridMatesControlTypeface = Atkinson` for body, actions, metadata, hint text. The puzzle grid itself should stay opt-in / existing number-letter customization, not be overridden. Later propagate to Sudoku only after owner compares Word Search on phone.

- Compare fullscreen Home with earlier WS-16R: Quick Play no longer dominates; Together feels reasonably similar in icon presence to Daily; gold divider visually balances footer; typography reads cozy but is still legible; shelf gain in wood grain and contact depth is appreciable at real handset scale.
- Check the full Book Library, Solo puzzle, Settings, Standard mode and large-font accessibility at least once. No book catalog/play state changes.
