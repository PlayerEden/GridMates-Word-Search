# WS-16S / WS-16T / Typography QA — button harmony, cozy shelf and reusable type system

**Purpose:** Owner confirmed visual refinement comes first and asked to do WS-16S (last button harmony) and WS-16T (more painterly/cozy shelf). They also asked whether GridMates should use a distinct downloadable free/commercially licensable font across the series. This is a first controlled Word Search implementation; Sudoku must not be silently changed.

## Exact source

- **WS-16S buttons:** Quick Play illustrated icon 46→43dp, title now same `titleSmall` as actual actions instead of larger `titleMedium`, subtitle muted and still honestly “coming soon”; Together squirrel 36→39dp in compact row; bottom Custom/My Puzzles now have an 18dp thin antique-gold divider. Continue Solo, main Play and Daily action routes, native clickable hitboxes and book carousel stay exactly as before. No extra permanent Home height.
- **WS-16T shelf paint/patina trial:** Preserves the original independently rendered seven-piece layered `WS16G` shelf art and its SHA-pinned SVG/PNG registry. A new lightweight `Ws16TShelfPatina.kt` Canvas layer introduces **deterministic irregular wood-grain brushwork**, warm pigment pooling, softer bracket-edge depth and undershelf shading; gold center medallion remains a separately drawn crisp top layer. Same 42dp shelf size / no new image downloads, random flicker, user interaction or save writes. This is deliberately a *trial overlay*, not a claim that the newly illustrated painterly shelf artwork image is already imported as a production asset.
- **GridMates typeface pilot:** `GridMatesTheme.kt` replaces generic system serif headings with **Literata** and generic system sans controls/text with **Atkinson Hyperlegible**. These are two different text roles: warm storybook/book-like serif for heading hierarchy, highly legible clean UI for buttons/progress/instructions. Text remains actual Android Unicode/native selectable/scalable text, **not rasterized into new images**. Long terms and large Android fonts remain accessibility QA requirements. Shared *intent* applies to the series, but no actual Sudoku code change in this Word Search pass.

## License/provenance / no vendor lock-in
- Both fonts were sourced from Google’s open font repository and offered under SIL Open Font License 1.1. According to [SIL’s own FAQ](https://software.sil.org/oflt/), an application (including a sold game or mobile app) can bundle original OFL fonts without licensing the whole game under OFL; fonts may not be sold alone, the redistributed font license notices must accompany them, and modified fonts with reserved names may require renaming.
- **Atkinson Hyperlegible** already appeared in `design/font-library-approved-b5.json` with source-pinned Google Fonts commit `24ddc1f324cac5d9f5aedca126d298f56e3f1640`, Git blob SHA and SHA-256.
- **Literata** added as fifth entry to the *same pinned source commit* and exact upstream font Git blob SHA `0a81b4984a4a4eb101e0ddc28babc85bb137efef`, 955,132 bytes, matching official OFL notice SHA `9d3b4e3b1e9068fbda799f57833ff831d05cc271`, 4,389 bytes. The current import validates pinned Git blob hashes and byte counts; no independent SHA256 value was asserted for the new source. `scripts/import_font_library.py` imports unchanged source binary and its complete legal notice into `app/src/main/res/font/gm_literata.ttf` and `app/src/main/assets/font_licenses/literata_ofl.txt`. No network dependency after app installation and no font file supplied directly to end users.
- Both GitHub QA workflows now sparsely check out this fifth family from the already-pinned Google Fonts commit, use the same import script, and bundle the font in the Android app. Android QA also checks five font IDs/notice paths are in the resulting APK.
- **Future GridMates series tokens**: `GridMatesStoryTypeface = Literata` for headings/section titles, `GridMatesControlTypeface = Atkinson` for body, actions, metadata, hint text. The puzzle grid itself should stay opt-in / existing number-letter customization, not be overridden. Later propagate to Sudoku only after owner compares Word Search on phone.

## Risks / acceptance
- Android font weights, accents, ellipsis and TalkBack magnification require real device verification; variable Literata could have different glyph metrics from the default serif. Preserve 48dp tap targets and let shorter/narrower devices scroll rather than clipping headings.
- The shelf improvement is **non-destructive** but subtle. If source screenshot still reads too clean, the correct next pass is to convert/approve painterly shelf art into separately scaled pieces for the QA asset registry, not just repeatedly add random Canvas noise.
- Compare fullscreen Home with earlier WS-16R: Quick Play no longer dominates; Together feels reasonably similar in icon presence to Daily; gold divider visually balances footer; typography reads cozy but is still legible; shelf gain in wood grain and contact depth is appreciable at real handset scale.
- Check the full Book Library, Solo puzzle, Settings, Standard mode and large-font accessibility at least once. No book catalog/play state changes.
